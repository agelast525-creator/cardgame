# 双人在线枪毙纸牌

一款支持手机竖屏的双人实时在线纸牌游戏。使用一副 54 张扑克牌，通过同花色压牌、王牌和“枪毙”展开对战，先打空手牌的玩家立即获胜。无需下载 App，创建房间并分享链接，即可邀请好友远程对战。

## 在线游玩

**游戏已上线：[点击开始游戏](https://cardgame-dbd7.onrender.com)**

网址：https://cardgame-dbd7.onrender.com

1. 用手机或电脑浏览器打开网站并创建房间，房主默认昵称为 player1。
2. 点击“复制邀请链接”，通过微信等方式发给好友。
3. 好友打开邀请链接并加入，默认昵称为 player2，双方自动开始游戏。点击自己昵称旁的铅笔图标可修改昵称，保存后立即同步给对方。

公网版无需连接同一个 Wi-Fi，也无需在自己的电脑上启动服务。游戏托管于 Render 新加坡区域，使用免费方案；服务闲置后首次打开可能需要等待唤醒，服务休眠或重启后需重新创建房间。

## 技术栈

React + TypeScript + Vite 前端，Node.js + Socket.IO 权威后端。洗牌、规则验证和胜负判定由服务器处理，客户端无法获取对方未公开手牌。

## 开发运行
在项目根目录执行：
```sh
npm install
npm run dev
```
打开终端显示的 Vite 地址（默认 http://localhost:5173）。创建房间，复制邀请链接。
本机测试请点击「打开第二个玩家页面」，该页面使用独立的会话身份，避免同一个浏览器恢复成同一玩家。

## 手机局域网测试
电脑与手机连接同一 Wi-Fi。使用 Vite 输出的 Network 地址在手机打开，再创建房间并复制链接。
前端通过同源 /socket.io 代理连接后端，因此手机不会误连自己的 localhost。
localhost 链接只能在当前设备使用。关闭服务终端会终止游戏。

## 生产运行
```sh
npm run build
PORT=3001 npm start
```
后端同时提供前端页面与 Socket.IO，单一端口。部署到支持常驻 Node.js 与 WebSocket 的服务器，用 HTTPS 反向代理转发 HTTP 和 WebSocket。
生产命令必须从本项目根目录运行。.env.example 仅供参考，不自动加载；使用 shell 或托管平台设置环境变量。
当前公网版本已部署到 Render：https://cardgame-dbd7.onrender.com 。仓库中的 render.yaml 提供免费 Web Service 部署配置。以上命令用于自行部署，本网站的玩家无需执行。

## 已实现
- 服务器随机洗牌、54 张牌、底牌王牌、双方各 8 张、首手花色比较。
- 普通压制、王牌、续出数字、枪毙、吃牌、换先后手、立即获胜。
- 每回合结束均补牌，包含吃牌。先结算桌面归属，再按实际出牌顺序循环补到 8 张；未出牌玩家补入循环末尾。超过 8 张不弃牌，牌堆不足则摸完。
- 手中仅剩枪毙时从废牌堆顶部按每张 3 张惩罚，当前桌面牌不参与。
- 玩家只能收到自己的手牌，对手仅数量；摸牌堆和废牌堆仅数量。
- 服务端身份、所属房间、行动角色、牌权、牌局版本检查；失败操作返回明确提示。
- 普通页面 localStorage 保存随机身份凭证，刷新与网络重连可恢复；本机第二玩家使用 sessionStorage。不要分享凭证，只分享邀请链接。
- 对方断线暂停，无超时自动判负。同一身份新连接取代旧连接。
- 竖屏界面、中文王牌底牌、合法手牌提示、点选/取消、出牌确认、防重复点击、吃牌二次确认、配对桌面、规则说明、胜负显示。

## 当前边界
房间保存在服务器内存中。网络短断可重连，服务器重启后牌局会丢失；这是单进程版本，不能直接横向扩容。
特殊规则尚待玩家确认：先手仅剩枪毙且废牌堆为空时，没有合法先手动作，界面会提示。本版本没有擅自判负、跳过或从其他牌堆摸牌。
没有人工浏览器视觉验收记录；已通过构建与真实 Socket.IO 连接测试。
